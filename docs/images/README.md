# Documentation Screenshots

Place screenshots used by the documentation in this directory. Suggested
filenames:

-   `server-running.png`
-   `claude-connected.png`
-   `tool-tests.png`
-   `security-tests.png`

Before committing screenshots, confirm that they do not reveal
passwords, `MCP_AUTH_TOKEN`, authorization codes, PKCE verifiers,
session cookies, access tokens, private workspace content, or other
sensitive information.

From a Markdown file in `docs/`, reference an image with a relative path
such as:

``` markdown
![Claude connector connected](images/claude-connected.png)
```

Only include screenshots that show actual results from the current
version.
